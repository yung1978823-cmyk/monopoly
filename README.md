# 大富翁 · 每日棋盤

這一版只做每日那一層：一塊自己的棋盤、四個地標、骰子、分數，以及一位內建對手可以來砸地標。

沒有公開桌、沒有賽季獎、沒有領地、沒有鏈上錢包、沒有 Solana。

## 這一層怎麼玩

- 沒有 NFT 也可以走。分數不能換成 DST，也不計入賽季。
- 骰子不出售。每 30 分鐘補 1 顆，最多存 20 顆。
- 開局手上有 2 顆。「擲骰行棋」擲兩顆並在自己的棋盤上走。
- 多數格子只加分數。踩到標著「攻擊」的格子，才進入「搜尋敵人」，自動配到阿強。
- 阿強自己擲兩顆，和是敵人幸運值。你的武器是已建成的地標，0 至 4。「用武器攻擊」跟他的戰鬥力加幸運值比。武器更大才打中：砸一座，並且在「我有 NFT」打開、對方有錢包時，按一日 5 DST 的上限拿走。否則打唔中，沒有損傷，也沒有 DST。
- 「起地標」蓋起下一座空著或已成廢墟的地標。戰鬥力等於已建成的地標數，0 至 4。
- 攻擊也花 2 顆。幸運值是兩顆的和。攻擊合計＝自己的戰鬥力＋幸運值。防守合計＝對方的戰鬥力。低過拿 0 DST；等於拿 1 DST；高過拿 min(5, max(2, 攻擊 − 防守 + 1))，且不超過防守方剩餘錢包，也不超過當日 5 DST。
- 只有 1 顆時，走一步和攻擊都會說明還要再一顆。
- 「我有 NFT」是試作開關。關掉時 DST 進出是 0。打開時可以放出最多 5 DST，對手阿強是帶 5 DST 錢包的 NFT 防守方。
- 阿強在這台裝置上，不連線。

棋盤會記在這台瀏覽器裡。沒有帳號，也沒有資料庫。

## 本地執行

需要 Node.js 20 或以上。

```bash
npm install
npm run dev
```

瀏覽器打開 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

`npm run dev` 會聽 `0.0.0.0:43123`。

## 測試
