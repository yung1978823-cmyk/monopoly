# 大富翁 · 第一層

這一版是第一層：每日自己的棋盤。一個人也能走、起地標、搜尋敵人。

沒有公開桌、沒有賽季獎、沒有領地、沒有鏈上錢包、沒有 Solana。完整三層寫在 `docs/`。

## 本地執行

需要 Node.js 20 或以上。

```bash
npm install
npm run dev
```

瀏覽器打開 [http://127.0.0.1:43123](http://127.0.0.1:43123)。開發伺服器聽 `0.0.0.0:43123`。

棋盤記在這台瀏覽器裡。沒有帳號，也沒有資料庫。

## 這一層怎麼玩

- 打開先看到棋盤，一圈 28 格。手上有 2 顆。「擲骰行棋」擲 2 粒骰、只扣 1 顆，走 2 至 12 格，棋子沿路亮起來。
- 棋盤有七格「攻擊」，每 4 格一格，每擲一次大約 22% 至 28% 踩中。踩到任何一格才搜尋敵人，自動配到阿強。阿強擲 2 顆，和是幸運值。
- 總攻擊＝10＋已建成地標×5。總防守＝對方建築×5＋幸運值。總攻擊更大才打中。
- 有 NFT 嘅對手開打時有一面盾；冇 NFT 嘅對手冇盾，第一下就打得爛建築。打中而且盾還在：盾破，得 1 分，DST 0。
- 盾破之後要揀對方一座建築先可以再打；打中就打爛嗰座。對方冇建築就只計分。
- 被打爛嘅地標唔再計武器，修返半價。被打冇分。☰ 入面有「被攻擊（測試）」可以試。
- 盾破之後再打中：分數是總攻擊減總防守，最少 1、最多 5。兩邊都有 NFT 時，搬走的 DST 等於這筆分數，一日最多 5。有一邊沒有 NFT，就只計分數，DST 0。
- 沒打中：0 分，0 DST，盾留著。
- 起地標要花分數：第 1 座 5 分，第 2 座 10，第 3 座 15，第 4 座 20（`lib/rules.ts` 的 `BUILD_COSTS`，可以再調）。企在未建的地標格上就先起那一座。
- 棋盤中間同搜尋畫面都顯示「今日 DST x／5」。
- 「我有 NFT」和「對手有 NFT」開局都開著。

## 攻擊畫面

- 踩中攻擊格，會入到阿強嘅城市：海港、花園或者市中心，隨機一個（`lib/cities.ts`）。
- 四座建築上面有瞄準圈。有 NFT 嘅阿強有盾，要先撳「打個盾」；盾破咗或者佢冇 NFT，就直接撳建築打落去。
- 打中會彈出結果：盾擋住、打爛咗、打中或者打唔中。打完撳「返回棋盤」。

## 裝落手機（PWA）

呢個遊戲係 PWA：放上網之後，可以加到手機主畫面，全屏打開，好似 App 咁。

- 打開先見主畫面（`public/art/title.jpg`），載入完撳「開始遊戲」。
- 遊戲畫面固定一版：頂部分數同今日 DST，中間棋盤，底部 GO 掣同起地標。☰ 入面有 NFT 開關、補骰（測試）同重開棋盤。
- `public/manifest.webmanifest`：App 名、圖示、全屏、直向。
- `public/sw.js`：離線快取，只喺 `npm run build` 之後嘅正式版啟用，開發模式唔會用。
- iPhone：用 Safari 打開網址 → 分享 → 加入主畫面。Android：Chrome 會彈「安裝」，或者喺選單揀「加到主畫面」。
- 要喺手機裝，一定要放上 https 網址；本機 `127.0.0.1` 只可以喺電腦試。
